# Projeto SOS Hospitalar
SOS Hospitalar
O SOS Hospitalar é um sistema de gestão de emergência hospitalar desenvolvido com o objetivo de automatizar e centralizar os processos de atendimento, reduzindo tarefas manuais e melhorando a eficiência operacional.

A plataforma busca facilitar a comunicação entre os profissionais de saúde, organizar o fluxo de pacientes e permitir um acompanhamento mais eficiente dos atendimentos.

Problema identificado

Os processos manuais e a falta de centralização das informações podem ocasionar:

* Perda de tempo em tarefas repetitivas.
* Dificuldade no acesso às informações.
* Atrasos na tomada de decisões.
* Desorganização do fluxo de atendimento.

Público-alvo

* Recepcionistas.
* Enfermeiros.
* Médicos.
* Administradores hospitalares.
* Pacientes.

Objetivo principal

Automatizar o fluxo de atendimento de emergência hospitalar por meio de uma plataforma centralizada, facilitando o gerenciamento de pacientes, a triagem e o acompanhamento dos atendimentos.

Principais funcionalidades

* Autenticação e controle de acesso por perfil.
* Cadastro e consulta de pacientes.
* Triagem e classificação de risco.
* Organização da fila de emergência.
* Gerenciamento de atendimentos.
* Registro de exames e diagnósticos.
* Histórico e acompanhamento dos pacientes.
* Consulta de indicadores e relatórios.

Requisitos do sistema

Requisitos funcionais

* RF01: Autenticação segura por perfil.
* RF02: Exportação de relatórios personalizados.

Requisitos não funcionais

* RNF01: Tempo de resposta inferior a 2 segundos.
* RNF02: Interface responsiva e acessível.

Metodologia de desenvolvimento

O projeto utiliza metodologias ágeis, com:

* Sprints quinzenais.
* Quadro Kanban para acompanhamento das tarefas.
* Planejamento integrado.
* Reuniões de alinhamento e retrospectivas.
